# Видеоигра "Космо бой"
"Космо бой" - классический аркадный шутер. Управляйте пушкой, у которой несколько жизней, уничтожайте волны инопланетных захватчиков и зарабатывайте очки за каждого сбитого пришельца. Игра запоминает ваш лучший результат, что мотивирует побить собственный рекорд. Простая механика, одна цель - выжить и набрать максимум.
